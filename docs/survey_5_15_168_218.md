## Out-of-path find (Batch 31, v0.32.0)

The listings above were harvested **per path** (fs/, mm/, sched/, net/, block/,
…), so a commit whose only hunk sits in `arch/arm64/include/asm/pgtable.h` is
invisible to this survey by construction.  One such commit is worth a row — it
was found by asking about a v6.18 commit (`143937ca51cc`) rather than by
sweeping this branch:

| group (child) | upstream commits (sublevel) | target files |
|---|---|---|
| arm64_pte_mkwrite_clean (core) | 8a2375b0e9b8 (.196; mainline 143937ca51cc, v6.18) | arch/arm64/include/asm/pgtable.h |

`pte_mkwrite()` cleared `PTE_RDONLY` unconditionally, and on arm64 that clear is
exactly what marks a page hardware-dirty (`PAGE_SHARED` is clean by default), so
a writable-but-unwritten page was reported dirty and written back at reclaim.
Read [CHANGELOG.md#batch-31](CHANGELOG.md#batch-31) before reading its benefit as
general: the commit's motivating `do_swap_page()` case does **not** exist on
5.15 (there mkwrite is paired with mkdirty), so the live call sites are the
transient-unmap restorers (`remove_migration_pte()`, `do_numa_page()`,
userfaultfd).  A future survey should add `arch/arm64/include/asm/` to its path
set instead of assuming the path-scoped listings above are exhaustive.

## Deferred backlog — every entry resolved (Batch 20, v0.25.0)

These are genuine feature/perf commits but were deferred because their
hunks chain on AOSP-drifted contexts (rmqueue region vendor deltas, NOHZ
helpers) or because their value is narrow for a phone GKI.  The section is
kept as the record of *why* each was deferred and *how* it was closed; the
full narrative is CHANGELOG.md#batch-20 (items 3–5) and
CHANGELOG.md#batch-6 (items 1–2).

1. **Gorman reserve-semantics deep water** (.171–.194): ca8527f25736
   (rmqueue_buddy split), c1b8856c5a7d, 17dedfd6de69, 85f58ee33c6c,
   4c4e238d3ada, 735457683e23 (ALLOC_HIGHATOMIC/OOM reserve semantics).
   Requires hand-anchoring against the AOSP rmqueue() region; the
   self-consistent rename + RT pair already landed as
   `pagealloc_min_reserve_semantics`.
2. **sched/fair dst-group stats** (.212): d99f14f8b142 — find_idlest path,
   needs fair.c anchor rework around AOSP vendor hooks.
3. **sched steal-time catch-up cap** (.179): 56135262c1f9 — **landed** as
   `sched_steal_time_excess_drop` (Batch 20).  The "near-zero value" note was
   about a bare-metal phone; the block is compiled in (the GKI defconfig sets
   `CONFIG_PARAVIRT_TIME_ACCOUNTING=y` because the same image boots as a KVM
   guest) but sits behind `paravirt_steal_rq_enabled`, so it is a constructive
   no-op on bare metal and live inside a guest.  Recorded, not hidden.
4. **sched u64 bandwidth ratios** (.210): 64d9b734b6fe — **rejected**: the
   commit fixes 32-bit truncation/wrap, and this module only ever builds
   arm64 (LP64), where `unsigned long` already is 64 bits.  Respelling three
   types would change no width, no value and no comparison.
5. **blk-mq quiesced elevator switch** (.209): 9646443f28f3 — **landed** as
   `blk_mq_quiesced_elevator_switch` (Batch 20).  The overlap objection died
   with the ABI-suite red line: since Batch 15 the suite must not ride the
   same build (`AGENTS.md`), and the absorbed `blk_mq_async_depth` anchors in
   `__blk_mq_alloc_request()` / `blk_mq_init_allocated_queue()` /
   `blk_mq_update_nr_requests()` — disjoint from this group's call sites.
6. **newidle_balance rename** (.196), iov_iter initializer renames (.210),
   inode sysctls file move (.179): churn without user-visible value.
